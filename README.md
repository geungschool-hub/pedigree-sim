# 가계도 분석하기 (pedigree-sim)

고등학교 진로선택 「생물의 유전」 웹 활동 — 교과서 23쪽 해보기 「가계도 분석하기」의 인터랙티브 버전.

- [자료 1] PTC 미맹 가계도: 우성/열성 판단 → 근거 가족을 가계도에서 직접 탭, 상염색체/성염색체 판단 → 근거 탭
- [자료 2] 적록색맹 가계도: 14명 전원 유전자형 입력(Xᴿ·X′, 확정 불가 포함)·채점, Ⅲ-9의 X′ 전달 경로 추적(2→4→9)
- 정리하기 4문항(모범답안) + 도전 가계도(우성 형질 판별)
- 단일 HTML · 오프라인 동작 · 태블릿/폰 터치 지원 · 진행 자동 저장(localStorage)
